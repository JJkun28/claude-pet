# 使用说明

## 操作

- **左键拖动**：移动位置（自动记住）。
- **左键单击**：随机播一个点击回应动作。
- **左键双击**：打开对话框，直接给 Claude 桌面版里的会话发消息（见下面「对话框」）。
- **右键**：菜单。
  - 顶部显示当前状态和进行中的会话数，下面是「打开 Claude Code」（没开就启动，开着就切到前台）和「和 Claude 说话…」。
  - 「工作状态 / 小动作 / 玩耍 / …」：列出动画包里的全部动作，点哪个就播哪个，播完回到当前状态。
  - 「按状态预览」：预览思考、工作、等待等状态的动画。
  - 大小、换宠物（`pets/` 下有多个动画包时出现）、始终置顶、待机时随机小动作、开机自启。
  - 接入 Claude Code（hooks）、重置会话状态、查看 hook 事件日志、重新加载配置和动画。
  - 「隐藏」：先藏起来，下次在 Claude Code 里发消息时自动出现。
  - 「彻底退出」：关掉，并且 hook 不再自动拉起它。想再打开就双击 `claude-pet.exe`（或开机自启），之后恢复自动拉起。
- 桌宠被隐藏时，再双击一次 `claude-pet.exe` 也会让它出现（不会多开）。

## 托盘图标

任务栏右下角有一个桌宠图标（用当前宠物生成，换宠物时跟着换；新图标默认在 `^` 展开区里，可以拖到任务栏上常驻）。

- **左键**：显示 / 隐藏桌宠。
- **右键**：和桌宠的右键菜单一样。桌宠隐藏时，菜单里的「隐藏」会变成「显示桌宠」。
- **鼠标悬停**：显示宠物名字和当前状态。
- 不想要托盘图标：把 `config.json` 里的 `tray` 改成 `false`。

## 对话框

双击桌宠（或右键「和 Claude 说话…」），桌宠上方会弹出一个输入框（上方放不下就放在下方，拖动桌宠时跟着走）。

- 第一行是**发送目标**，默认是 Claude 桌面版里最近活跃的会话，后面带着文件夹名和桌宠记录到的状态。
  点这一行可以从最近 15 个会话里另选一个；输入框只有一行字时，按 ↑ / ↓ 也能切换。
- **Enter** 发送，**Shift+Enter** 换行，**Ctrl+A** 全选，**Esc** 或点别处关闭。没发出去的字会留着，下次打开还在。
- 发送时桌宠会用 `claude://code/continue?session=…` 让桌面版切到那个会话，等窗口到前台、页面渲染好以后，
  把字打进 Claude 的输入框并按回车。消息出现在桌面版里，和你手打的一样。打字不经过剪贴板。
- 桌面版没开时会先把它启动起来（最多等 20 秒）。切不过去的话，会把要发的话复制到剪贴板并提示你手动粘贴。
- 会话列表来自桌面版自己存的会话文件（`%LOCALAPPDATA%\Claude-Data\…\claude-code-sessions`）。
  想看桌宠读到了哪些会话，可以在命令行运行 `claude-pet.exe sessions`。
- 只支持 Claude 桌面版的 Code 会话，终端里跑的 `claude` 不支持。

## 状态逻辑

| Claude Code 事件 | 桌宠状态 |
|---|---|
| UserPromptSubmit | 思考中 |
| PreToolUse、SubagentStart、PreCompact | 工作中（AskUserQuestion 工具算「等待你确认」） |
| PostToolUse、PostToolUseFailure | 整理结果 |
| PermissionRequest、Notification(permission_prompt) | 等待你确认 |
| Stop | 完成（展示 `success_secs` 秒后回待机） |
| StopFailure | 出错（展示 `error_secs` 秒后回待机） |
| Notification(idle_prompt) | 回待机（被 Esc 中断时 Claude Code 不发 Stop，靠这个） |
| SessionEnd，或该会话的 Claude 进程已退出 | 回待机 |

- 思考、工作、整理、等待会**一直保持**，直到收到下一个事件。不会因为超时被待机动作打断。
- 多个会话同时进行时，显示优先级最高的那个：**等待你确认 > 出错 > 工作中 > 思考中 > 整理结果 > 完成**。
  所以一个会话做完、另一个还在干活时，不会提前庆祝。
- 状态降级（例如 工作中→整理结果）前至少保持 `hold_ms` 毫秒，防止来回闪。
- 待机随机小动作和点击回应会被状态变化立即打断；右键点播的动作会完整播完。

## 接入 Claude Code 时改了什么

「接入 Claude Code」会在 `%USERPROFILE%\.claude\settings.json` 的 `hooks` 里，给 12 个事件各加一条
`"<exe 完整路径>" hook` 命令，其余配置原样保留。每次修改前都会备份为 `settings.json.claude-pet-<时间戳>.bak`。

- hooks 里记的是 exe 的完整路径。文件夹挪了位置后，在新位置打开一次桌宠，它会自动把路径改过来。
- 「断开」只删除桌宠自己的那几条，不影响你别的 hooks。
- 命令行也可以操作：`claude-pet.exe install` / `claude-pet.exe uninstall`。
